    The problem
    
Prose breaks pipelines.

    

      Agent outputs are written for humans — hedging, vague, hard to act on mechanically.
      The moment another agent needs to consume them, the cracks show.
    


    

      

        

          
        

        
Ambiguous by default

        
"Should probably", "might be", "let me know" — prose that hedges can't be routed or branched on.

      

      

        

          
        

        
No shared contract

        
Each agent invents its own format. No validator can enforce consistency across producers in a pipeline.

      

      

        

          
        

        
Evaluation doesn't scale

        
Without structure, checking correctness means LLM-as-judge or manual review — neither is CI-ready.

      

    

  







  

    The contract
    
Four shapes. One contract.

    

      Each shape maps to a real moment in multi-agent orchestration.
      Pick the right one, emit valid JSON, and your output is machine-readable — no parsing required.
    


    

      
      

        
        
        
        
      


      
      

        

          
handoff

          
Transfer ownership to the next agent. You disconnect — everything they need to continue without re-reading chat history is in the payload.

          

            Use when
            
    
              
  • A worker finishes its slice and passes to a verifier
    • 
              
  • A session ends and the next session must start from state
    • 
              
  • Implementation is done — tests and review are someone else's job
    • 
            

          

        

        

          

            handoff.json
            
          

          

        

      


      
      

        

          
status

          
Report progress while you keep working. Ownership stays with you. The orchestrator gets a state-machine view — not a prose update.

          

            Use when
            
    
              
  • You're mid-task and the orchestrator needs a checkpoint
    • 
              
  • You're blocked and need to surface the blocker explicitly
    • 
              
  • Periodic progress reports in a long-running task
    • 
            

          

        

        

          

            status.json
            
          

          

        

      


      
      

        

          
decision

          
A routing or strategic choice with rejected alternatives preserved. Orchestrators can audit "why did this agent do that?" without parsing prose reasoning.

          

            Use when
            
    
              
  • An orchestrator is deciding which worker to spawn
    • 
              
  • A strategic choice was made between real options
    • 
              
  • You want rejected alternatives in the audit log
    • 
            

          

        

        

          

            decision.json
            
          

          

        

      


      
      

        

          
debug

          
Failure with a routable next_action. The orchestrator branches on an enum — no parsing the error message.

          

            next_action values
            
    
              
  • retry — spawn the same worker again
    • 
              
  • escalate — notify human or upgrade to a stronger agent
    • 
              
  • abort — cancel the workflow
    • 
              
  • investigate — spawn a debugger / reader agent
    • 
            

          

        

        

          

            debug.json
            
          

          

        

      

    

  







  

    

      

        Evaluation
        
Deterministic checks.
Not vibes.

        

          When agents produce prose, checking correctness means LLM-as-judge or human review.
          SignalShape outputs can be validated with a CLI that exits non-zero on violations.
          Wire it into CI. No custom validation logic.
        

        

          

            

              
            

            

              
CI-ready

              
Run signalshape lint in your pipeline. Exit 0 = valid. Fails before a malformed message reaches another agent.

            

          

          

            

              
            

            

              
Schema-enforced

              
JSON Schema draft-2020-12 via ajv. Required fields, enum constraints, regex on producer IDs — enforced, not hoped for.

            

          

          

            

              
            

            

              
Six exit codes

              
Valid, invalid, malformed JSON, unknown shape, prose-only shape, usage error. Orchestrators branch on them — no prose parsing.

    Deployment
    
Use it where you need it.

    
Same contract, three entry points. Pick the one that fits how your agents run.


    

      

        
01

        
As a skill

        
Install into compatible agent tools, or paste the prompts into any agent setup. The agent answers with the right shape on demand — JSON when another agent may consume the output, prose for humans.

        

          $ ./scripts/install.sh claude
        

      

      

        
02

        
As repo instructions

        
Paste into AGENTS.md or CLAUDE.md. SignalShape becomes the default behavior for every agent in the repo — no manual invocation.

        

          cat prompts/repo-instructions.md >> AGENTS.md
        

      

      

        
03

        
As agent contract

        
Use schemas in schemas/ in your pipeline. One agent's output becomes another's validated input. No ad-hoc parsing, no guessing.

        

          $ ./bin/signalshape lint output.json
        

      

    

  







  

    Positioning
    
Why not just use X?

    
Real alternatives exist. The honest comparison:


    

      

        Comparison of SignalShape with alternative tools
        
          

            Tool
            What it does
            What it doesn't do
          

        
        
          

            humanizer
            Strips AI tells from prose output
            No machine contract. Output still not parseable by agents.
          

          

            caveman
            Compresses tokens aggressively
            No structure for downstream agents to route on.
          

          

            Structured prompting
            Ad-hoc JSON schemas per task
            No shared contract across producers. No versioning. No validator.
          

          

            SignalShape v0.1
            Versioned contract, 4 JSON schemas, CLI validator, worked multi-agent demo
            Not a transport. Not an SDK. Not a full multi-agent protocol.
          

        
      

      

        If your agent only talks to humans, those tools cover you. If its output is consumed by another agent,
        SignalShape gives you a checkable contract that survives across producer / consumer pairs.

    FAQ
    
Common questions.


    

      

        
        

          

            A lightweight communication contract for AI agents. Four machine-validatable JSON shapes — handoff, status, decision, debug — so agents produce structured outputs instead of unstructured prose. Ships with a CLI validator, JSON Schema draft-2020-12, and a worked multi-agent demo.
          

        

      

      

        
        

          

            Structured prompting defines ad-hoc schemas per task — no shared contract across agents, no versioning, no validator. SignalShape is versioned (v0.1.0) and shared: signalshape lint enforces compliance deterministically across all producers and consumers in a pipeline.
          

        

      

      

        
        

          

            Framework-agnostic. Works as schemas plus a CLI for any pipeline, as repo-level instructions in files such as AGENTS.md or CLAUDE.md, or as optional skill adapters for compatible agent tools. No SDK required — just schemas and a Node.js validator.
          

        

      

      

        
        

          

            Run ./bin/signalshape lint output.json. Exit 0 = valid. Exit 1 = schema violation. Exit 2 = malformed JSON. Also from stdin: cat output.json | ./bin/signalshape lint -. Batch validation supported — highest exit code wins.
          

        

      

      

        
        

          

            Schemas for review and implement, npm package distribution, Hooks or adapters for popular agent runners with harness-level enforcement, A2A and MCP compatibility analysis, correlation_id for multi-agent tracing, and empirical token-saving benchmarks. Deliberately out of v0.1 scope.
